# Sistem Keluhan - Sprint 9

Aplikasi ini dibangun untuk memenuhi tugas Sprint 9 mata kuliah Web Development. Aplikasi ini menerapkan State Management (useState) dan Event Handling sesuai standar React.

## Pembagian Tugas:
- **[Nama Anggota 1]**: Navbar, Footer, & Styling (CSS Modules).
- **[Nama Anggota 2]**: ListKeluhan.jsx, rendering list (.map), & KeluhanItem.
- **[Nama Anggota 3]**: FormKeluhan.jsx, State Management, & Event Handling.

## Fitur Utama:
- Menggunakan `useState` untuk menyimpan data keluhan.
- Menggunakan `spread operator` untuk menambah keluhan baru.
- Menggunakan `CSS Modules` untuk styling yang modular.
- Validasi form sederhana.
